    Export for BigQuery

    The download holds every decision the team has made, with the source name, the CEEB code (or the new school's name and city), the level and state for the school code, any notes, who decided, and when. It holds no player data. The same decisions live in the team's Google Sheet.

    To build the BigQuery tables, save the JSON into hs_registry/exports/ and run:

    py hs_registry/export_bigquery.py hs_registry/exports/<file>.json

    That writes hs_master (one row per active CEEB high school, with one column per source listing every name it uses and a blank vt_name) and hs_alias (one row per linked source name, used to relabel incoming data), plus BigQuery schema files. Names marked needs research go to a separate hs_research.csv and stay out of both tables until they're resolved.

    Keyboard

    For the new school codes (<LEVEL>-<ST>-<6-digit ID>), pick the level and check the state before saving. The 6-digit IDs are assigned afterward by assign_school_ids.py, so no two people can hand out the same number.
